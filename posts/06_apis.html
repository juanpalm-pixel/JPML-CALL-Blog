Understanding APIs

March 9th 2026 Hilary Term

What exactly is an API?

An Application Programming Interface, or API, is essentially a service. While we interact with apps through buttons and screens, an API allows a user to communicate with a service directly via code. Think of it as the reception desk of a hotel, or a bouncer for a club. You've likely used them without even realizing it --Google Maps provides maps and directions via API, Spotify uses them for music streaming--.

Public vs. Private Interfaces

Not all APIs are open to everyone. Public APIs, like Spotify’s, act as creative tools that let developers build new apps (such as Receiptify and Airbuds). Conversely, private APIs are used internally by companies like Amazon to allow different parts of their system to talk to each other securely without exposing sensitive functions to the public.

Designing a RESTful API

Most modern APIs follow "RESTful" principles (Representational State Transfer), which involve four basic operations: POST (write new info), GET (retrieve info), PUT (edit info), and DELETE. For example, if you use the Abair synthesis API to turn text into speech, you use a POST request because the audio file doesn't exist yet and must be created. If you’re just checking your Spotify login details, you're using a GET request to view existing information.

The Three Pillars of an API Gateway

As systems grow complex, developers often use an API Gateway to centralize multiple APIs. While a single API acts as a gateway to its own service, a true Gateway acts like an "address book" for many different APIs. A well-designed Gateway rests on three pillars:

  • Gatekeeping: This involves security through API Keys and "Rate Limiting" to ensure no one abuses the service.
  • Observability: Developers use tools like Grafana to monitor traffic and identify bottlenecks or "bad actors".
  • Documentation: This is the most vital pillar; if a developer can't understand how to use your service, nobody will use it.

By providing clear lists of endpoints, example requests, and response codes, an API becomes a powerful tool for scaling language learning technologies.

In summary, APIs are essential for connecting different software systems and enabling seamless integration of language learning features.
